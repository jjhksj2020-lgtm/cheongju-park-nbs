# 공공기관 제출용 기업 문서 스킬

## 0. 작성 전 확인 (없는 것만 한 번에 짧게 묻기)
- 제출처(시·부서)와 근거가 되는 공고문·과업지시서·제안요청서(RFP). 있으면 반드시 먼저 읽고, 서식·목차·분량·평가항목을 그대로 따른다. 공고문 서식이 이 스킬의 기본 구조보다 우선한다.
- 문서 종류, 제출 형식(HWP/HWPX, PDF, DOCX), 마감일, 분량 제한
- 회사 정보: 회사명, 대표자, 사업자등록번호, 주요 실적, 보유 인력·인증·특허

## 1. 문체와 표기 원칙
- 개조식 명사형 종결("~추진", "~확보", "~예정")을 기본으로 하고, 서술형이 필요한 항목만 문장으로 쓴다.
- 항목 기호 순서(행정문서 관행): 1. → 가. → 1) → 가) → (1) → (가) → ① → ㉮. 장표형 보고서는 □ → ○ → - → · 를 쓸 수 있다. 한 문서 안에서는 하나로 통일한다.
- 날짜는 "2026. 11. 13.", 시간은 "14:00", 금액은 천 단위 쉼표와 단위(원, 천원, 백만원)를 표 머리에 명시한다. 공문의 금액은 "금 1,250,000원(금일백이십오만원)" 형식.
- 공문은 수신·(경유)·제목 → 본문 → 붙임(목록과 부수) → 본문 끝에 "끝." 표시. 발신명의와 직인 자리를 비워 둔다.
- 약어는 처음 나올 때 풀어 쓴다. 과장·최상급 표현("국내 최초", "혁신적")은 근거가 있을 때만 쓰고 근거를 같이 적는다.

## 2. 사업계획서·제안서 기본 구조
1. 사업 개요: 사업명, 기간, 대상·지역, 총사업비(시비·자부담 구분), 수행기관
2. 추진 배경 및 필요성: 시의 정책 방향·계획과 연계, 현황 문제를 통계로 제시
3. 사업 목표 및 성과지표: 최종 목표 1개 + 세부 목표, 지표별 현재값·목표값·측정 방법·측정 시점
4. 세부 추진 내용: 전략 → 과제 → 세부 활동 순으로 구조화
5. 추진 체계: 조직도, 투입 인력(성명 대신 직급·역할·경력), 협력기관
6. 추진 일정: 월별 간트차트, 주요 마일스톤과 산출물
7. 소요 예산: 비목별(인건비·운영비·여비·재료비 등) 표, 산출 근거는 "단가 × 수량 × 기간 = 금액", 합계 검산
8. 기대효과: 정량(숫자)과 정성 구분, 시민·지역에 돌아가는 효과 중심
9. 위험 요인 및 대응, 사후관리·지속 방안
10. 수행 역량: 유사 실적(발주처·기간·금액), 인증·특허

평가항목이 주어지면 목차를 평가항목 순서에 맞추고, 각 절 제목에 평가항목 용어를 그대로 쓴다. 제출 전 "평가항목 ↔ 본문 위치" 대조표를 만들어 빠진 항목이 없는지 확인한다.

## 3. 결과·성과보고서
계획 대비 실적을 표로 대조(목표값 / 달성값 / 달성률), 미달성 항목은 원인과 보완 계획을 적는다. 예산은 예산액 / 집행액 / 집행률 / 잔액과 증빙 목록. 사진·증빙자료는 붙임으로 번호를 붙여 정리한다.

## 4. 근거·통계·데이터
- 통계는 공신력 있는 출처를 우선한다(국가통계포털 KOSIS, 공공데이터포털, 해당 시의 통계연보·계획서). 표·그림 아래에 "자료: 기관명, 자료명(기준연도)"를 단다.
- 출처를 확인할 수 없는 수치는 만들지 않고 "[확인 필요]"로 표시한다.
- 계산(합계·비율·증감률)은 코드나 수식으로 검산하고, 본문·표·요약의 숫자가 서로 일치하는지 확인한다.
- 성과지표는 측정 가능하고 사업과 직접 연결된 것으로, 투입 → 산출 → 결과 → 영향 단계를 구분한다.
- 상관관계를 인과로 쓰지 않는다. 표본·기간의 한계는 명시한다.

## 5. 제출 전 점검표
- 공고문의 필수 서류·서식·분량·파일 형식 충족
- 회사명·사업명·금액·기간이 문서 전체에서 일치
- 예산 합계 검산, 단위 표기, 쪽번호·목차 일치
- 개인정보(주민번호·연락처) 불필요한 노출 없음, 대외비 정보 표시
- 다른 사업·타 기관 문서를 복사한 흔적(다른 지자체명 등) 없음
