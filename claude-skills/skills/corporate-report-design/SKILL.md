# 기업 문서·장표 디자인 스킬

## 디자인 방향
신뢰·정돈·가독성이 우선이다. 장식보다 정보 구조로 완성도를 만든다. 평가위원이 짧은 시간에 훑어보고도 핵심을 잡을 수 있어야 한다.

## 브랜드 기준
- 회사 CI(로고, 전용 색상 HEX 값, 전용 서체)가 있으면 그것을 따른다. 없으면 먼저 한 번 물어본다.
- 색 체계: 주색 1(CI 색) + 보조색 1 + 강조색 1(핵심 수치·경고만) + 회색 단계. 채도 높은 색을 넓은 면에 쓰지 않는다.
- 흑백 인쇄에서도 구분되도록 색만으로 의미를 전달하지 않는다(패턴·라벨 병행).

## 서체
- 제출 형식을 먼저 확인한다. HWP 제출이면 수신측에 없는 서체가 깨지지 않도록 기본 서체(함초롬바탕·돋움, 맑은 고딕 등)를 쓰거나 PDF를 함께 제출한다.
- 장표·PDF는 상업적 사용이 허용된 서체(예: Pretendard, 나눔스퀘어, 본고딕)만 쓴다. 서체는 2종 이내.
- 크기 단계를 고정한다. 장표 예시: 헤드메시지 20~24pt / 소제목 14~16pt / 본문 11~12pt / 주석 8~9pt.

## 장표형 보고서·제안 발표
- 장표마다 상단에 헤드메시지(그 장의 결론 한 문장)를 두고, 본문은 그 결론의 근거만 담는다.
- 헤드메시지만 이어 읽어도 전체 논리가 이어지도록 구성한다.
- 구성: 표지 → 목차 → 요약(Executive Summary) → 본문 → 기대효과 → 회사 소개·실적 → 붙임.
- 텍스트보다 도식: 프로세스는 흐름도, 구조는 계층도, 일정은 간트차트, 비교는 표, 수치는 차트.

## 표·차트 규칙
- 표는 세로선을 최소화하고 머리행만 색을 넣는다. 숫자는 오른쪽 정렬, 단위는 머리에.
- 차트는 말하려는 것만 강조색, 나머지는 회색. 3D·그림자 효과는 쓰지 않는다.
- 모든 표·그림에 번호·제목·출처("자료: …")를 단다.

## 보고서(문서형) 레이아웃
- 표지: 사업명, 제출처, 제출일, 회사명·로고. 과한 이미지 금지.
- 머리말(문서명)·꼬리말(쪽번호), 여백 일정, 장 시작은 새 쪽.
- 강조는 굵게 또는 박스 하나로 통일한다. 밑줄·색·굵기를 섞지 않는다.

## 홍보물·웹·앱 화면
- 공공 사업 홍보물은 시 로고·사업명 표기 규정이 있는지 확인하고 따른다(임의로 변형 금지).
- 웹·앱은 웹 접근성(한국형 웹 콘텐츠 접근성 지침)을 고려한다: 대비 4.5:1 이상, 대체 텍스트, 키보드 조작, 충분한 터치 영역.

## 저작권
- 이미지·아이콘·서체는 상업적 사용 라이선스를 확인한 것만 쓴다. 타사 로고·캐릭터·인물 사진은 쓰지 않는다.

## 내기 전 점검
- 헤드메시지만 읽었을 때 논리가 이어지는가
- 서체·색·글자 크기·항목 기호가 전 페이지에서 일관된가
- 표·그림 번호와 출처, 쪽번호·목차가 맞는가
- 흑백 인쇄·PDF 변환 후에도 깨지지 않는가
