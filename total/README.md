지도는 하나이고, 맨 위 **주제 [사업성 | 열저감 | 이용성]** 를 바꾸면 같은 지도 위의 색·기둥·목록·공원 카드·비교 막대가 그 주제로 바뀝니다.
공원을 누르면 오른쪽 카드 안에서도 **[사업성 | 열저감 | 이용성]** 탭으로 두 정보를 오갈 수 있습니다.

| 주제 | 도시 전체 색 | 기둥(3D) | 공원 카드 | 비교 막대 |
|---|---|---|---|---|
| 사업성 | 국공유 비율 · 집행 단계 · 경계 일치도 · 건물·시가지 사유지 | 시 부담 최대 · 사유지 면적 | 면적·국공유·공시지가·시 부담·보상 단가·단계와 근거 | 공원별 보상비+조성비 |

공원 상세(필지 지도)는 두 주제 공통입니다. 필지 색은 소유·이용상황·용도지역·지목·공시지가 중에서 고릅니다(열저감 주제에서는 이용상황이 기본).

## 발표판 (2026-11-20)

최종본은 **발표용 페이지가 앞에 붙은 한 파일**입니다. 위쪽 단계 버튼이나 아래 [이전·다음](키보드 ←·→)으로 넘깁니다.

1. **주제·목적** — 무엇을 왜 하나, 세 가지 기준
2. **공원이란** — 도시공원 종류(대상 40곳 유형별), 실효 연도 분포, 왜 순서가 필요한가
3. **이용성** · 4. **에너지저감** · 5. **사업성** — 각각 ① 왜 보나 → ② 평가 구조 → ③ 대시보드(통합 지도, 해당 주제로 고정) → ④ 결과(핵심 숫자·상위 5곳·해석)

자잘한 근거·가정·전체 표는 각 칸의 **상세보기(+)** 안에 접어 두었습니다. 숫자는 모두 지도 데이터(세 파트 결과)에서 계산하고, 1단계 실효년도·민간특례 면적·월명공원 검증값은 `biz/code/params.yaml`에서 읽습니다.
지도 엔진을 못 불러오면(오프라인) 대시보드 칸에만 안내가 뜨고 설명·결과는 그대로 보입니다.

- `code/present_shell.html` 발표 페이지 틀·디자인 · `code/present_shell.js` 페이지 내용·넘기기 · `code/present_map.js` 지도 보정 · `code/present.py` 지도에 씌우기
- 지도 보정(발표판만): 지도는 가로 16:10, 오른쪽 패널은 지도 높이에 맞춤. 항공사진·일반지도·3D 지형을 청주시 경계 모양으로 잘라 보여 줌. 공원은 원 대신 도시계획시설 경계 모양(검은 테두리)으로 그리고, 3D를 누르면 그 모양이 값만큼 솟으며 도심 쪽으로 기울어 확대됨. 작은 공원은 위치 점을 함께 표시.
- `build_total.py` 가 마지막에 자동으로 씌웁니다. 계산 없이 발표판만 다시 만들려면 `python total/code/present.py` (기존 최종본 안의 데이터를 그대로 씀).

## 이 폴더는 읽기만 합니다

각 파트의 계산은 그 파트 폴더에서 하고, 여기서는 결과를 합쳐 보여 주기만 합니다(파트 폴더는 고치지 않음).

| 읽는 것 | 파트 |
|---|---|
| `biz/out/mapdata.json` (공원·필지·시 부담·단계) · `biz/data/map/` (위성사진·지형) | 사업성 |
| `energy/out/mapdata.json` (공원별 열저감 값, 청주 계수) | 열저감 |
| `need/out/edc_map.json` (공원별 E·D·C 값) · `need/out/indicators_edc.csv` (지표별 자료·tag) | 이용성 (③ 인구·토지·생활권, need/edc) |

## 만들기 (저장소 맨 위 폴더에서)

```bash
pip install pyyaml                       # 처음 한 번
python total/code/build_total.py         # 세 파트 계산을 차례로 돌린 뒤 → total/청주_장기미집행_공원_40개소_조성_지도.html
```

- 계산은 다시 하지 않고 지도만 다시 만들려면 `--no-run`.
- 사업성 지도 틀(`biz/code/map_template.html`)이 바뀌면 먼저 `python total/code/make_template.py` → 통합 틀(`code/total_template.html`)을 다시 만듭니다.
