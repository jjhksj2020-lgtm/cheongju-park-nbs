# 청주 장기미집행 공원 40개소 조성 지도 — 사업성 + 열저감 통합 지도

**최종본: [`청주_장기미집행_공원_40개소_조성_지도.html`](청주_장기미집행_공원_40개소_조성_지도.html)** — 내려받아 더블클릭하면 열립니다(위성사진·지형 포함, 지도 엔진만 인터넷에서 불러옴).
GitHub 웹에서는 코드만 보이니 **Download raw file** 로 받아서 여세요.

지도는 하나이고, 맨 위 **주제 [사업성 | 열저감]** 를 바꾸면 같은 지도 위의 색·기둥·목록·공원 카드·비교 막대가 그 주제로 바뀝니다.
공원을 누르면 오른쪽 카드 안에서도 **[사업성 | 열저감]** 탭으로 두 정보를 오갈 수 있습니다.

| 주제 | 도시 전체 색 | 기둥(3D) | 공원 카드 | 비교 막대 |
|---|---|---|---|---|
| 사업성 | 국공유 비율 · 집행 단계 · 경계 일치도 · 건물·시가지 사유지 | 시 부담 최대 · 사유지 면적 | 면적·국공유·공시지가·시 부담·보상 단가·단계와 근거 | 공원별 보상비+조성비 |
| 열저감 | 성격(조성형·보전형) · 냉각량 · 공원 일대 저감 · 지금 녹지(NDVI) · 등급 | 냉각량(제곱근) · 공원 일대 저감 | 지금 녹지 → ①녹지 증가 → ②공원 일대 저감 → ③주변 300m → ④냉각량, 땅 상태, 근거 | 공원별 냉각량 기준·범위 |

공원 상세(필지 지도)는 두 주제 공통입니다. 필지 색은 소유·이용상황·용도지역·지목·공시지가 중에서 고릅니다(열저감 주제에서는 이용상황이 기본).

## 이 폴더는 읽기만 합니다

각 파트의 계산은 그 파트 폴더에서 하고, 여기서는 결과를 합쳐 보여 주기만 합니다(파트 폴더는 고치지 않음).

| 읽는 것 | 파트 |
|---|---|
| `biz/out/mapdata.json` (공원·필지·시 부담·단계) · `biz/data/map/` (위성사진·지형) | 사업성 |
| `energy/out/mapdata.json` (공원별 열저감 값, 청주 계수) | 열저감 |

## 만들기 (저장소 맨 위 폴더에서)

```bash
pip install pyyaml                       # 처음 한 번
python total/code/build_total.py         # 두 파트 계산을 차례로 돌린 뒤 → total/청주_장기미집행_공원_40개소_조성_지도.html
```

- 계산은 다시 하지 않고 지도만 다시 만들려면 `--no-run`.
- 사업성 지도 틀(`biz/code/map_template.html`)이 바뀌면 먼저 `python total/code/make_template.py` → 통합 틀(`code/total_template.html`)을 다시 만듭니다.

```
total/
  청주_장기미집행_공원_40개소_조성_지도.html            최종본
  README.md
  code/
    make_template.py        사업성 지도 틀 + 열저감 화면 → total_template.html
    total_template.html     통합 지도 틀
    build_total.py          두 파트 결과 합치기 → 청주_장기미집행_공원_40개소_조성_지도.html
```
