# 06. 전체 루트 — 공원 조성 → 열저감 → 에너지저감 → 탄소저감 (확정안, 2026-11-20)

## 원칙
1. **가상 데이터 0.** 모든 입력은 실측·공식 공표 자료다. 문헌 계수는 결과의 교차검증에만 쓰고 계산에는 넣지 않는다.
2. **"조성 후" 상태도 실측으로 정한다.** 미래의 공원은 아직 없으므로, "실제로 조성된 공원이 조성 후 어떤 상태가 되었나"(05의 사례 공원 실측 NDVI·지표온도)를 조성 후 값으로 쓴다. 가정한 숫자를 넣지 않는다.
3. **범위는 실측 변동에서.** 각 단계 계수의 범위는 사례 간 차이나 회귀의 신뢰구간으로 정한다(몬테카를로 없음).
4. **단계마다 실측 검증**을 하나씩 붙인다. 검증에 실패한 단계는 결과를 내지 않고 "자료 부족"으로 표시한다.

## 한눈에
```
[R1] 공원 조성 → 지표온도(LST) 변화            실제 조성 사례 전후 + 청주 변화 픽셀 (Landsat·Sentinel-2)
      ↓  ΔLST (공원 안 · 거리별 고리)
[R2] 지표온도 → 기온                            기상청 AWS·ASOS 기온 × 같은 시각 Landsat LST (+ 서울 S-DoT 검증)
      ↓  ΔTair
[R3] 기온 → 건물 냉방 전력 반응                  건물·단지별 월 전력(건축HUB·K-apt) × ASOS 일기온 → kWh/냉방도일
      ↓  건물 유형별 β
[R4] 공원별 냉방 전력 절감                       영향권 건물(건축물대장·GIS건물통합) × β × ΔTair → ΔkWh/년
      ↓
[R5] 탄소 저감                                   ΔkWh × 국가 전력 배출계수(공식 공표) → tCO₂eq/년
      (+ 조건부) 조성 수목 흡수                    실제 식재 계획이 있을 때만: 수종·수량 × 국립산림과학원 표준 흡수량
[R6] 전 구간 실측 검증                            실제 조성된 공원 주변 아파트의 조성 전후 전력 변화(DiD)
```

## 단계별

### R1. 공원 조성 → 지표온도 변화
| 항목 | 내용 |
|---|---|
| 입력(실측) | 실제 조성 사례(부산시민공원 2014, 서울식물원 2019, 세종중앙공원 2020 + 1~10ha급 중소 사례) 전후 여름 Landsat LST, Sentinel-2·Landsat NDVI, V-World 공원 경계 / 청주 NDVI 변화 픽셀 76,985칸(`energy/`) |
| 방법 | 장면별 도시 평균 대비 LST(LSTa) → 조성 전후 차 − 대조 지역 차(DiD). 공원 안, 0–100, 100–300, 300–500m 고리별 |
| 출력 | 공원 조성 1건의 ΔLST(공원·거리별), 조성 후 실측 NDVI, 면적별 효과 곡선 |
| 청주 적용 | 청주 조성형 공원마다 지금 NDVI·면적을 넣어, 사례에서 실측한 면적별 효과 곡선으로 ΔLST 산출 |
| 검증 | 사례끼리 교차(한 사례를 빼고 맞춘 곡선으로 그 사례를 예측) |
| 상태 | 설계 완료(05), 경계 수집·GEE 실행 전 |

### R2. 지표온도 → 기온
| 항목 | 내용 |
|---|---|
| 입력(실측) | 기상청 ASOS 청주(131)·청주권 AWS 시간별 기온, 같은 날 Landsat 통과 시각(오전 10~11시) LST |
| 방법 | 관측소 간 **차이끼리** 회귀: (관측소 기온 − 기준 관측소 기온) ~ (관측소 LST − 기준 LST). 공원이 만드는 건 "동네 간 차이"라서 절대값이 아니라 차이의 비율 k가 필요 |
| 출력 | k (ΔTair = k × ΔLST) 와 그 신뢰구간 |
| 국내 선행 | 수도권 AWS와 Landsat LST의 회귀 기울기 0.45(MODIS 1.02) 보고. 서울 흑석동 연구는 AWS로 LST→기온 모형(R² 0.97)을 만들고 독립 S-DoT 센서로 검증 |
| 검증 | 서울 S-DoT(촘촘한 실측 기온 센서)로 공원 주변 실제 기온 차이와 비교 |
| 위험 | 청주 관측소가 적다 → k의 범위가 넓을 수 있음. 그 경우 서울 S-DoT로 구한 k를 범위로 함께 표시하고 출처를 분리 |

### R3. 기온 → 건물 냉방 전력 반응
| 항목 | 내용 |
|---|---|
| 입력(실측) | 건물별 월 전력(건축HUB 건물에너지), 공동주택 단지별 에너지(K-apt), ASOS 청주 일평균 기온 |
| 방법 | **같은 건물의 달별·연도별 변동**으로 학습: 월 전력 = 기저 + β × 냉방도일(CDD) (건물 고정효과). 공간 비교(동네 간)는 쓰지 않음(교란) |
| 출력 | 건물 용도·규모별 β (kWh/㎡/°C·일) 와 신뢰구간 |
| 검증 | 한전 청주 용도별 월 판매량의 여름 증가분과 건물 합계가 맞는지 |
| 위험 | 건물에너지 자료는 단독주택·200세대 미만 공동주택 제외(가스 자료 기준 확인됨, 전기 자료 범위는 받아서 확인) → 적용도 같은 범위로 한정하고 비율을 표시 |

### R4. 공원별 냉방 전력 절감
| 항목 | 내용 |
|---|---|
| 입력(실측) | R1 ΔLST(거리별), R2 k, R3 β, 영향권 안 건물(건축물대장 용도·연면적, GIS건물통합 위치), ASOS 실제 냉방일수 |
| 방법 | 건물마다 ΔTair = k × ΔLST(그 건물 거리) → ΔCDD = ΔTair × 그해 실제 냉방일수 → ΔkWh = β × ΔCDD × 연면적. 공원별 합 |
| 출력 | 공원별 연간 냉방 전력 절감 kWh (범위) |

### R5. 탄소 저감
| 항목 | 내용 |
|---|---|
| ① 회피배출(주) | ΔkWh × **국가 전력 배출계수**. 최신 공표값 2023년 0.4173 tCO₂eq/MWh(국가 온실가스 통계 관리위원회, 2025-12 공표, 이후 매년 갱신). 계산 시점의 최신값과 공표일을 기록 |
| ② 수목 흡수(조건부) | **실제 식재 계획(수종·수량·규격)**이 있을 때만: 국립산림과학원 표준 탄소흡수량(수종·수령별)·도시수목 실측 흡수량으로 계산. 계획이 없는 공원은 계산하지 않음(가상 식재 금지) |
| 출력 | 공원별 tCO₂eq/년 (①, ②를 따로 표시하고 합치지 않음) |

### R6. 전 구간 실측 검증 (가장 중요)
| 항목 | 내용 |
|---|---|
| 아이디어 | **이미 조성된 공원 주변 아파트의 실제 전력이 조성 후 줄었나**를 직접 본다. R1~R4 사슬이 예측한 절감량과 비교 |
| 후보 | 서울식물원(2019 개원) 주변 마곡 아파트 단지 — 2016~18 vs 2020~22, 공원에서 가까운 단지 vs 먼 단지(DiD). K-apt 단지별 자료 |
| 판정 | 실측 절감이 사슬 예측 범위와 맞으면 사슬 채택. 실측 효과가 잡음보다 작으면 "예측 절감은 검출 한계 이하"로 정직하게 표기하고 범위 상한만 제시 |

## 결과물 형태 (예정)
- 공원별 표: ΔLST(공원·300m) → ΔTair → ΔkWh/년 → tCO₂eq/년, 각 단계 최소~최대, 각 계수의 출처 자료
- 지도: 공원 영향권 안 건물별 절감
- 근거 대장: 단계별 입력 자료·공표일·URL (저장소 `evidence/` 규칙과 같은 형식으로 이 폴더 안에)

## 진행 순서와 필요한 것
| 순서 | 작업 | 필요한 것 |
|---|---|---|
| 1 | R1 사례 측정 | 사례 공원 경계(V-World, 브라우저) · GEE 실행(브라우저, 기존 프로젝트) |
| 2 | R3 자료 확인 | 건축HUB·공공데이터포털 로그인(본인) → 청주 건물 전력 1개월치로 범위 확인 |
| 3 | R2 | 기상자료개방포털 AWS·ASOS(로그인 필요할 수 있음) |
| 4 | R6 자료 | K-apt 마곡 단지 자료 |
| 5 | R4·R5 계산·검증 | 위 결과 |
