# 06. 전체 루트 — 공원 조성 → 열저감 → 에너지저감 → 탄소저감 (상세안, 2026-11-20)

## 0. 원칙
1. **가상 데이터는 쓰지 않는다.** 계산에 들어가는 값은 모두 실측값이나 공식 공표값이다. 문헌 계수는 결과를 비교하는 데만 쓴다.
2. **"조성 후" 상태도 실측으로 정한다.** 아직 없는 공원 대신, 실제로 조성된 공원이 조성 뒤에 어떻게 바뀌었는지(R1)를 쓴다.
3. **기준값도 데이터에서 구한다.** 냉방 기준온도 같은 값도 가정하지 않고 데이터로 추정한다(R3).
4. **범위는 실측 변동에서 정한다.** 사례 간 차이, 회귀 신뢰구간, 실제 연도별 날씨 차이를 쓴다. 몬테카를로는 쓰지 않는다.
5. **단계마다 통과 기준을 둔다.** 기준을 못 넘은 단계는 숫자를 내지 않고 "자료 부족"으로 표시한다.

```
R1 조성 → ΔLST(거리별)  →  R2 ΔLST → ΔTair  →  R3 기온 → 건물 전력 반응 β
                                                    ↓
R6 전 구간 실측 검증  ←  R5 탄소(tCO₂eq)  ←  R4 공원별 ΔkWh
```

## R1. 공원 조성 → 지표온도 변화 (거리별)

**질문:** 공원이 없던 땅에 공원이 생기면 공원 안과 주변 몇 m까지 지표온도가 얼마나 내려가나?

### 사례 고르는 기준
- 조성 전에 녹지가 아니었던 땅이어야 한다. 시가지, 나대지, 농지, 군부대 터 등.
- 개장이 2015~2021년이어야 한다. Landsat 8·9로 조성 전 여름 2년 이상, 조성 후 여름 3년 이상을 볼 수 있다.
- 면적 구간마다 3곳 이상: 0.5–2ha / 2–10ha / 10ha 이상. 청주 조성형이 대부분 1ha 안팎이라 작은 구간이 꼭 필요하다.
- 같은 기간 주변에 대규모 개발이 없는 곳을 우선한다. 마곡·세종처럼 주변도 함께 개발된 곳은 따로 표시한다.
- 확정된 후보: 부산시민공원(2014.5), 서울식물원(2019.5), 세종중앙공원(2020.11). 중소 사례는 추가 조사가 필요하다.

### 자료
| 자료 | 내용 |
|---|---|
| Landsat 8·9 Collection 2 Level-2 | 지표온도 `ST_B10`, 구름 마스크 `QA_PIXEL`, 6~9월 |
| Sentinel-2 L2A, Landsat SR | NDVI (조성 전후 녹지 실측) |
| V-World 도시계획시설(공원) 경계 | 사례 공원 폴리곤 |

### 계산
1. 장면마다 **LSTa = 픽셀 LST − 그 도시 분석 범위의 중앙값**. 그날의 날씨 영향을 지운다.
2. 시기별(조성 전·후) 여름 장면의 LSTa **중앙값**을 픽셀마다 구한다.
3. 구역별로 평균을 낸다: 공원 안, 0–100m, 100–200m, 200–300m, 300–500m 고리.
4. **대조(DiD):**
   - 대조 구역 = 같은 도시에서 공원 경계 2km 밖, 같은 기간 NDVI 변화가 0.05 미만이고 땅덮개가 그대로인 픽셀
   - ΔLST(구역) = (후 − 전)_구역 − (후 − 전)_대조
5. **거리 감쇠:** ΔLST(d) = ΔLST₀ · exp(−d / L)을 사례마다 맞춘다. 결과는 공원 안 효과 ΔLST₀와 퍼짐 거리 L이다.
6. **자라는 효과:** 조성 후 1–2년 차와 3–5년 차를 따로 계산한다.

### 출력 (사례별 1줄)
`사례, 면적, 조성전 땅, 조성전·후 NDVI, ΔLST₀(공원 안), ΔLST(각 고리), L(m), 장면 수(전/후), 경과연수`

### 청주에 적용
- 청주 조성형 공원마다 면적 구간과 지금 NDVI를 확인한다.
- 같은 면적 구간 사례들의 실측 ΔLST₀와 L의 **최소~최대**를 쓴다.
- 사례가 10곳 이상이면 회귀를 쓴다: ΔLST₀ ~ ΔNDVI + log(면적). 그보다 적으면 구간별 범위만 쓴다.

### 통과 기준
- 각 면적 구간에 사례 3곳 이상
- 한 사례를 빼고 맞춘 식으로 그 사례를 예측했을 때 오차가 실측 범위 안

## R2. 지표온도 → 기온

**질문:** 지표온도가 동네끼리 1°C 다를 때 기온은 몇 °C 다른가?

공원이 만드는 것은 "옆 동네보다 시원함"이다. 그래서 절대값이 아니라 **차이끼리의 비율 k**가 필요하다.

### 자료
| 자료 | 내용 |
|---|---|
| 기상청 ASOS 청주(131) + 청주권 AWS | 시간별 기온, 일평균·일최고 |
| 같은 날 Landsat LST | 관측소 위치 3×3 픽셀(90m) 평균 |
| 서울 S-DoT 센서 | 촘촘한 실측 기온. 검증용 |

### 계산
1. 맑은 여름날 Landsat 장면마다 관측소 쌍 (i, j)를 만든다.
2. 두 가지를 짝지어 모은다.
   - ΔLST_ij = LST_i − LST_j
   - ΔTa_ij = 관측소 기온 차이. 세 가지로 각각 계산한다.
     - (a) Landsat 촬영 시각(약 10~11시) 기온
     - (b) 일평균 기온
     - (c) 일최고 기온
3. 회귀: ΔTa_ij = k · ΔLST_ij (+ 고도차 보정항). 결과로 k와 95% 신뢰구간을 낸다.
4. **R3·R4에는 (b) 일평균 기준 k를 쓴다.** 냉방도일을 일평균 기온으로 계산하기 때문이다. (a)와 (c)는 비교용으로 함께 표시한다.

### 통과 기준
- 관측소 쌍 × 장면 수 ≥ 30
- k의 신뢰구간이 0을 포함하지 않음

### 위험
- 청주 관측소가 적으면 k의 범위가 넓어진다.
- 그때는 서울 S-DoT로 구한 k를 **별도 줄**로 표시한다. 출처를 섞지 않는다.

## R3. 기온 → 건물 냉방 전력 반응 β

**질문:** 같은 건물이 기온이 1°C 높은 날을 하루 더 겪으면, ㎡당 전력을 얼마나 더 쓰나?

### 자료
| 자료 | 필요한 칸 | 비고 |
|---|---|---|
| 건축HUB 건물에너지(전기) | 건물 열쇠(지번/PNU), 사용년월, 사용량(kWh) | 형식·제공 범위는 받아서 확인. 가스 자료는 단독주택·200세대 미만 공동주택 제외로 확인됨 |
| 건축물대장 표제부 | PNU, 주용도, 연면적, 사용승인일, 세대수 | 건물 유형 묶기·㎡ 환산 |
| 공동주택 에너지(K-apt) | 단지코드, 년월, 전기 사용량 | 칸 구성은 명세 확인 필요 |
| ASOS 청주 일평균 기온 | 2016~2025 | 냉방도일(CDD) 계산 |

### 전처리
- 기간: 2016~2025년, 월 단위
- 건물당 유효한 달이 36개월 이상
- 제외: 신축 첫해, 사용량이 0이거나 급변한 달(공실·용도변경 의심), 연면적 없음
- 검침일이 달마다 달라서 1개월 어긋날 수 있다. 결과가 크게 흔들리면 2개월 창으로 다시 계산한다.

### 계산
1. **냉방도일:** CDD_m = Σ_그 달 날짜 max(0, T_일평균 − T_base)
2. **기준온도 T_base는 데이터로 찾는다.** 16~24°C를 0.5°C 간격으로 바꿔 가며 건물 유형별 모형 잔차가 가장 작은 값을 고른다.
3. **모형(건물 유형 g):**
   E_im / A_i = α_i + β_g · CDD_m + μ_y + ε
   - E_im: 건물 i의 m월 전력(kWh)
   - A_i: 연면적
   - α_i: 건물 고정효과. 건물마다 다른 기저 사용량을 흡수한다.
   - μ_y: 연도 효과. 요금·코로나 같은 해마다의 변화를 흡수한다.
   - → **같은 건물의 달별 변동**에서만 β를 배운다. 동네끼리 비교하지 않는다.
4. 건물 유형 g: 아파트, 단독·다가구(자료가 있으면), 업무, 판매·근린생활, 교육, 기타
5. 결과 표: β_g(kWh/㎡·°C·일), 95% 신뢰구간, T_base, 건물 수, 기간

### 통과 기준
- 유형별 건물 30동 이상
- β의 신뢰구간이 0을 포함하지 않음
- **합계 검산:** Σ(청주 건물 β × 연도별 CDD 변화 × 연면적)의 연도 간 증감이 한전 청주 여름 판매량 증감과 같은 방향이고 크기 차이가 2배 안

### 위험
- 자료에 없는 건물 유형(예: 단독주택)은 R4에서 **계산하지 않고 빠진 비율을 표시**한다. 다른 유형의 β를 빌려 쓰지 않는다.

## R4. 공원별 냉방 전력 절감

**질문:** 청주 공원 하나를 조성하면 영향권 안 건물들의 연간 냉방 전력이 얼마나 줄어드나?

### 자료
| 자료 | 내용 |
|---|---|
| 청주 공원 경계 | `biz/data/vworld/parks.txt` |
| R1 결과 | 그 공원 면적 구간의 ΔLST₀, L |
| GIS건물통합 + 건축물대장 | 건물 폴리곤, PNU, 주용도, 연면적 |
| R2, R3 결과 | k, β_g, T_base |
| ASOS 청주 실제 일기온 | 2021~2025년 각 해 |

### 계산 (건물 b마다)
1. **영향권:** 공원 경계에서 거리 d_b가 실측 L의 3배(효과가 약 5%로 줄어드는 거리) 안에 있는 건물
2. **지표온도 저감:** ΔLST_b = ΔLST₀ · exp(−d_b / L)
3. **기온 저감:** ΔTa_b = k · ΔLST_b
4. **냉방도일 저감 (해마다 실제 날씨로):**
   ΔCDD_b,y = Σ_그 해 날짜 [ max(0, T_d − T_base) − max(0, T_d − ΔTa_b − T_base) ]
   - 실제 일기온을 그대로 쓰기 때문에 "기준온도 근처 날은 효과가 작다"는 비선형이 자동으로 반영된다.
5. **전력 저감:** ΔE_b,y = β_g(b) · ΔCDD_b,y · A_b
6. **공원 합계:** ΔE_park,y = Σ_b ΔE_b,y
   - 한 건물이 두 공원 영향권에 모두 들면 **큰 쪽 하나만** 넣는다(이중 계산 방지).

### 범위 (몬테카를로 없이 조합)
| 요소 | 최소 쪽 | 최대 쪽 |
|---|---|---|
| R1 | ΔLST₀·L 최소 사례 | 최대 사례 |
| R2 | k 신뢰구간 하한 | 상한 |
| R3 | β 신뢰구간 하한 | 상한 |
| 날씨 | 2021~2025 중 가장 서늘한 해 | 가장 더운 해 |

- 최소 = 모두 최소 쪽, 최대 = 모두 최대 쪽, 기준 = 모두 중앙값

### 출력 (공원별 1줄)
`site_id, 영향권 건물 수, 그중 β 있는 유형 비율, ΔLST₀, L, 영향권 평균 ΔTa, ΔCDD(기준), ΔkWh/년(최소·기준·최대), 빠진 유형 연면적`

## R5. 탄소 저감

### ① 회피배출 (주 결과)
- ΔCO₂ = ΔkWh × 국가 전력 배출계수
- 최신 공표값은 2023년 0.4173 tCO₂eq/MWh(국가 온실가스 통계 관리위원회, 2025-12 공표)다.
- 비교용으로 직전 공표값(2020~2022 평균 0.4541)도 함께 표시한다.
- 매년 갱신되므로 계산 시점의 최신값과 공표일을 기록한다.

### ② 수목 흡수 (조건부)
- **실제 식재 계획(수종·수량·규격)이 있는 공원만** 계산한다.
- 근거: 국립산림과학원 표준 탄소흡수량(수종·수령별), 국내 도시수목 실측 흡수량(그루당 연간 kgCO₂)
- 계획이 없는 공원은 "식재 계획 없음 — 미산정"으로 표시한다.

### 표시
- ①과 ②는 **합치지 않고 따로** 보여 준다. 성격이 다르기 때문이다. ①은 매년 반복되는 배출 회피이고, ②는 나무가 자라는 동안의 흡수다.

## R6. 전 구간 실측 검증

**질문:** 실제로 공원이 생긴 곳에서 주변 건물 전력이 R1~R4가 예측한 만큼 줄었나?

### 설계
| 항목 | 내용 |
|---|---|
| 사례 | 서울식물원(2019.5 개원) 주변 마곡 아파트 단지 |
| 처리군·대조군 | 공원에서 500m 안 단지(처리) vs 500~1,500m 단지(대조) |
| 기간 | 조성 전 2016~2018년 여름, 조성 후 2021~2023년 여름. 2020년은 코로나로 생활 패턴이 바뀌어 뺀다 |
| 모형 | E_cm = α_c + λ_m + θ · (가까움 × 조성후) + ε. 단지 고정효과와 월 고정효과 |
| 자료 | K-apt 단지별 월 전력, 단지 위치, 세대수·면적 |

### 판정
1. θ(실측 절감)와 R1~R4로 그 단지들에 대해 예측한 절감을 비교한다.
2. θ의 신뢰구간이 예측 범위와 겹치면 → **루트 채택**
3. θ의 신뢰구간이 예측 효과보다 훨씬 넓으면 → **"검출 한계 이하"**. 예측 범위의 상한만 제시하고 그렇게 명시한다.
4. θ가 예측과 반대 방향으로 유의하면 → 루트를 재검토한다. R2와 R3를 먼저 의심한다.

### 미리 확인할 것
- 처리군 단지들의 입주 시점이 2016년 이전인지. 마곡 단지 입주 연도를 확인해야 한다.
