# 04. 시작 전에 정할 것

| # | 정할 것 | 선택지 | 추천 |
|---|---|---|---|
| 1 | 주 방법 | A 문헌 계수 / **B 청주 실측 회귀** / C 시뮬레이션 | **B 주 결과 + C 검증(근린공원8) + A 범위 표시** |
| 2 | 대상 공원 | 40곳 전부 / 조성형 17곳 / 1ha 이상 조성형 / 근린공원8 집중 | 계수(B)는 청주 전체 건물로 만들고, **적용은 조성형 17곳**. 설명·시뮬레이션은 근린공원8 |
| 3 | 결과 단위 | 연간 냉방 kWh / 여름 최대전력 kW / 원 / tCO₂ | 연간 냉방 kWh(주) → 원·tCO₂ 환산. 최대전력은 시간 자료가 없어 참고 |
| 4 | 건물 범위 | 공원 일대(1ha 칸) + 300m 고리 / 더 넓게 | `energy/`와 같은 범위(공원 일대 + 300m). 넓히려면 새 근거 필요 |
| 5 | 기준 기간 | 2023–2025 여름 / 패널용 2016–2025 | 횡단면은 2023–25. 자료가 되면 2016 대비 패널 추가 |
| 6 | 자료 받기 | 본인이 받아 첨부 / 로그인 뒤 내가 브라우저로 | 로그인만 본인, 나머지는 내가 |
| 7 | `energy/`와의 관계 | `energy/`를 고치지 않고 읽기만 / 결과를 `energy/`에 합치기 | **읽기만.** 합칠지는 결과를 보고 다시 결정 |

## 미리 알아둘 위험
- 건물 에너지 자료에 **단독주택·소규모 공동주택이 빠질 수 있다.** 근린공원8 주변(북문로 도심)의 건물 구성에 따라 적용 가능한 비율이 달라진다 → 자료를 받으면 가장 먼저 확인한다.
- 횡단면 회귀는 "더운 동네 = 다른 동네"라는 교란이 크다. 통제 후에도 계수가 불안정하면, 결과를 **범위로만** 내고 C(시뮬레이션)의 비중을 높인다.
- GEE 비상업 등록이라 **과제(학술) 용도로만** 쓴다.
