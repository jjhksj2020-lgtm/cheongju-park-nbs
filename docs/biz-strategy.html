③ 시 부담 분포

40개소 시 부담 최소를 크기순 막대로 그리고, 연 420억 × 1단계 4년 = 1,680억 실적선을 긋는다. 1단계로 배정된 후보지의 합이 이 선을 넘으면 등급 안 순서대로 2단계로 밀린다. 선은 예산 결정이 아니라 "지난 5년 속도로 가능한 범위"의 참고선이다.

④ 필요성 순위 × 시 부담

가로축 필요성 순위(필요성 파트), 세로축 시 부담 최소. 오른쪽 위(필요한데 비싼 곳)가 심의에서 가장 먼저 논의할 후보지이고, 특례 가능 후보지는 테두리로 강조한다.

단계 배정 규칙 — 필요성 판정은 받기만 하고, 사업성은 그 안의 순서를 정한다

1단계(2027~30)에 넣는 조건 · 하나라도 충족
  1. 실효년도 ≤ 2030 — 1단계 기간 안에 실효되므로 2단계로 두면 사라진다 (국토계획법 §48, 기본계획 승인 2027.12 제안서 p.6)
  2. 공고 1단계 — 시가 이미 집행계획에 넣은 2개소는 유지 (공고 제2026-2004호)
  3. 외부 재원 경로 ≥ 1 — 특례 가능 또는 국비 요건 충족. 시 부담 최소가 최대보다 작은 곳

판정이 "보류"면 단계를 주지 않는다. 특례 가능 → 민간 제안 대기 / 개발압력 높음(필요성 파트) → 실효 전 재검토 / 그 외 → 시 판단.

같은 등급·단계 안의 순서
  1. 시 부담 최소 낮은 순 — 같은 필요성이면 적게 드는 곳부터 (비용효과 순, 예타 일반지침의 비용효과 분석 원칙)
  2. 동률이면 국공유지 비율 높은 순 — 보상이 작고 즉시 착수 가능
1단계 합계 점검선

1단계 후보지의 시 부담 최소 합이 1,680억(연 420억 × 4년)을 넘으면 순서 뒤쪽을 2단계로 보낸다. 이 선은 2020~25 실적에서 온 참고선이고 예산 결정은 시가 한다.

절차와 판정
  1. 2 × 2 × 2 = 8개 조합마다 시 부담 최소와 단계를 다시 계산
  2. 8개 모두 단계가 같으면 확정, 하나라도 다르면 경계 — 문턱값 없음
  3. 경계 후보지는 전환값을 카드에 적는다. 예: "보상단가 29만원/㎡ 이상이면 1단계 합계 점검선을 넘어 2단계" → 담당자가 확인할 자료(감정평가·토지소유)가 바로 드러남
  4. 결과는 40행 × 8열 표 한 장과 경계 후보지 목록으로 보고

몬테카를로는 쓰지 않는다. 확률분포를 가정할 근거가 없고, 결과를 손으로 재현할 수 없어 심의 자료로 부적합하다.

이론과의 연결 (7주차 강의자료 쪽)

이론사업성 파트에서 쓰는 방식
문제구조화 (Rosenhead 1996, p.8)"사업성"을 수익성이 아니라 "시가 감당할 수 있는가"로 재정의해, 비구조적 문제를 금액 두 개와 플래그로 바꾼다
가치중심사고 (Keeney 1996, p.9)대안(어느 공모에 낼까)이 아니라 가치(시 재정 부담 최소화)에서 지표를 고른다
지식의 3조건 (Cash et al. 2003, p.9)현저성 = 예산 요구서·공모 신청서에 바로 쓰는 숫자 / 신뢰성 = 출처 키·실적 단가 / 정당성 = 해제 미판정, 가정 공개
PSS 실행 격차 (Vonk 2005; Jiang 2020, p.10)도구보다 사용자 먼저: 화면 요소를 담당자의 질문에서 역산. 담당자 접촉이 없으므로 필요성·사업성 파트 교차 검토로 대신
플랫폼 3종 (p.11) · 검증 3지점 (p.21)i-Tree의 입력→계산→화면 구조, 단 가중합 대신 금액 나열 · 엔드포인트·패키지·수치 검증 (§6)

04한계 (한계층)

한계영향받는 수치화면에서 다루는 방식
토지소유·공시지가 수령 전에는 사유지 100% 가정보상액이 최대 수십 배 과대 (생태공원3 사례). 미조성 공원 면적의 95.2%가 국유지(제안서 p.28)회색 "가정", 대형·생태공원은 "미산정". 수령 시 값만 교체
실적 단가가 두 건(강내·월명)뿐보상 23~34만, 조성 6.1~13.9만원/㎡ 범위가 넓음범위로 표시, 시 단가표 수령 시 교체. 공시지가 수령 후 배율로 전환
특례 "가능"은 법 요건만. 사업자 수요 미반영영운공원처럼 사업자 포기 시 시 부담 최소 0이 무효"법 요건 충족"으로만 표기, 최소값은 "특례 시"로 조건부
국비는 선정 불확실, 반환사업 요건 공고 원문 미확인시 부담 최소가 시나리오값단계 판정은 두 경우 모두 계산(§3), 요건은 공고 확인 후 룰 수정
필요성 지표 수령 전 국비 요건 판정 불가국비 경로 열 공란13주 수령 후 채움, 그 전엔 "검토"로 표기

06바이브코딩 프롬프트와 검증

도구는 Claude Code(수집·룰 엔진·화면)와 QGIS MCP(필지 공간조인). 프롬프트는 "어디서 어떤 값을 가져와 어떻게 계산하고 무엇을 표시하라"를 한 번에 담고 출처 키를 강제한다.

프롬프트 1 · 공시지가 수집
sites.csv(site_id, dong, jibun, area_m2) 40행에 대해 V-World 개별공시지가 API(api.vworld.kr, 키는 환경변수 VWORLD_KEY)로 지번별 ㎡당 공시지가를 가져와 land_price_krw_m2 열에 넣고, 응답 원본을 raw/vworld_{site_id}.json에 저장해라. 실패한 행은 값을 비우고 note 열에 사유를 적어라. 다른 도메인은 호출하지 말고 패키지는 requests와 pandas만 써라.
프롬프트 2 · 재원 룰 엔진 + 시나리오
rules.md의 룰 5개(특례·도시숲·생태축·반환·매수청구)를 함수로 만들어 sites.csv 각 행에 적용하고 city_cost_max, city_cost_min, funding_routes, buyout_cap, stage, source_keys 열을 추가해라. 단가는 params.yaml(보상 23만/34만, 조성 6.1만/13.9만원/㎡, 국비율 하한)에서만 읽고 코드에 숫자를 쓰지 마라. 보상×조성×국비 8개 조합으로 stage를 다시 계산해 scenario_{1..8} 열과 stage_stable(8개 동일 여부), switch_value 열을 만들어라. 마지막에 월명공원(102,487㎡, 사유지 100%)을 넣어 상한 단가에서 보상 351억·조성 63억이 나오는지 출력해라.
